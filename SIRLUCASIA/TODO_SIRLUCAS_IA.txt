TODO SOBRE SIRLUCAS IA
======================

SIRLUCAS IA es un asistente de IA orientado a memoria, proyecto, contexto y automatización local.

1. PROPÓSITO
------------
El sistema combina:
- memoria persistente
- reglas textuales para interpretar comandos
- gestión de contexto de usuario
- tareas, documentos, archivos y sistema
- búsqueda y recuerdo de información relevante

2. ARQUITECTURA PRINCIPAL
-------------------------
- app/core: lógica central del asistente
- app/modules: parsers, handlers y reglas del proyecto
- app/service: gestión de documentos, sistema y operaciones
- app/utils: utilidades compartidas, JSON y helper functions
- data/: archivos de persistencia y datos del asistente
- tests/: validaciones de componentes principales

3. FUNCIONALIDADES ACTUALES
---------------------------
- Memoria persistente en JSON
- Guardado y recuerdo de datos personales
- Guardado y recuperación de proyectos
- Auto-guardado cuando aparece un proyecto en una conversación
- Búsqueda por memoria, categoría, relevancia y tags
- Histórico de conversación
- Gestión de documentos, archivos, documentos de texto y otros formatos
- Interacción con sistema operativo y programas
- Lógica basada en reglas (regex) mediante RuleEngine
- Preparación de módulos de web, conocimiento y cálculo

4. COMPONENTES DESTACADOS
-------------------------
- MemoryManager: administrador de memoria con persistencia, índices y CRUD
- ConversationManager: orquesta los turnos de conversación
- RuleEngine: interpreta patrones textuales y extrae valores de grupos
- ProjectMemoryIntegration: conecta reglas de proyecto con MemoryManager
- ProjectMemoryHandler: ejecuta la lógica concreta de guardar/recuperar proyectos
- JSONManager: garantiza lectura/escritura segura de JSON y manejo de directorios

5. CÓMO GUARDA UN PROYECTO
-------------------------
Cuando el usuario escribe frases como:
- "mi proyecto es SIRLUCAS IA"
- "trabajo en IAGENERATOR que es un sistema de IA"

el RuleEngine detecta la regla y la integración llama a MemoryManager.remember_project().
Esto guarda el proyecto en memoria permanente con categoría projects.

6. CÓMO SE RECUPERA
-------------------
Frases como:
- "¿cuál es mi proyecto?"
- "lista mis proyectos"

permiten consultar la información guardada.

7. PERSISTENCIA
---------------
La memoria se guarda en:
- data/memory.json

También se maneja backup asociado a:
- data/memory_backup.json

8. ESTADO ACTUAL
----------------
El proyecto está operativo en su parte central de memoria/proyectos.
Se corrigieron los bloqueos reales que impedian el funcionamiento del flujo.
